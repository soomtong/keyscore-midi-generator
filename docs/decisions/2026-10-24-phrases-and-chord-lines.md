# 프레이즈 카탈로그와 코드 라인 (2026-10-24)

## 배경
이 앱은 가상악기/외장악기의 음색을 고르는 도구다. 음색은 귀에 익은 선율과 코드 진행으로 들어야 감이 잡힌다.
멜로디 듣기는 AI 프롬프트용 MelodyStyle(Free(AI) + 14개 일반 패턴)을 그대로 재생했고, 진행은 한 마디 한 코드의 짧은 다이아토닉 진행 8개뿐이었다.
개인용 비공개 바이너리라 유명 곡을 담아도 라이선스를 고려하지 않는다.

## 결정

### 멜로디: MelodyStyle 을 Phrase 카탈로그로 바꾼다 (Phrase.swift)
- Free(AI) 항목을 없앴다. 멜로디 듣기는 항상 로컬에서 재생된다. 곡 생성에는 곡 생성 탭의 "프레이즈 성격" 토글(기본 끔)을 켠 경우에만
  선택한 프레이즈의 선율 성격(character, 곡명 없음)과 밀도(notesPerBar)가 프롬프트에 들어간다. 항상 넣으면 멜로디 탭을 만지지 않은 사용자의 모든 곡에
  기본 프레이즈(Ode to Joy)의 성격이 숨은 편향으로 들어가기 때문이다. 곡명을 넣지 않는 이유는 LLM 이 저작권 멜로디 재현을 거부할 수 있어서다.
  밀도는 곡이 늘 4/4 라 3박자 프레이즈도 4박 기준으로 환산하고, 셋잇단 프레이즈면 분수 박 허용 힌트를 붙인다. character 에는 박자를 적지 않는다.
- 분류: 클래식 · 민요/캐럴 · 훅/리프 · 테마/클라이맥스 · 게임 · 에튀드. 에튀드는 옛 패턴 중 음색 시험에 쓸모 있는 5개(Scale Run, Arpeggio, Triplet Run, Pentatonic Riff, Long Tones)만 남겼다.
- 유명 프레이즈는 원곡의 장/단조(scale)를 고정하고 Key 만 옮긴다. 선택한 스케일에 끼워 맞추면 선율이 망가져 알아듣기 어렵기 때문이다. 에튀드(scale == nil)만 선택한 스케일을 따른다.
- 음은 스케일 디그리 + 임시표(alter)로 적는다. 음수 디그리는 으뜸음 아래, 디그리 → 음높이는 floor 나눗셈으로 옥타브를 계산한다.
  옥타브는 선택한 Key 의 base(60 + root, F# 이상은 한 옥타브 아래)에서 원곡 음역에 가깝도록 정했다 (예: A 단조 곡은 A3 가 base 이므로 +7).
- 표기: `디그리[#|b][/길이]`, `r` 쉼표, `t`·`T` 는 셋잇단 8분/4분음표, `|` 는 무시. 리터럴 배열보다 틀리기 어렵고 읽기 쉽다. 파싱은 시작 시 한 번이다.
- 박자(meter)는 3 또는 4. 전체 길이는 마디 단위로 올림하며 고정 16박이 아니다. 3박자 프레이즈에는 드럼을 묶지 않는다.
- 변주(Vary)는 마디 첫 박과 임시표 음을 지키고 나머지를 30% 확률로 이웃 스케일 음으로, 끝음은 같은 옥타브의 1·3·5도로 바꾼다.

### 진행: Progression 을 ChordStep 목록으로 바꾼다 (Theory.swift)
- ChordStep = degree · alter(근음 반음 조정, bVII 등) · family(종류별 모드 위에 3도 쌓기) · quality(카탈로그 심볼 고정) · bass(슬래시 베이스 디그리) · beats.
- 기본 진행은 scale == nil 로 선택한 스케일 위의 다이아토닉. 모던 팝과 유명 코드 라인은 원곡 조성을 고정한다 (프레이즈와 같은 이유).
- 처음에는 기본 진행을 2박씩 두 바퀴 도는 "한 마디 두 코드" 묶음을 두었는데, 소리는 기본 진행과 같고 빨라질 뿐이라 뺐다.
  사용자가 원한 것은 현대 팝의 화려한 화성이었다. 모던 팝 묶음은 슬래시 코드와 하행 베이스, sus4 → 해결, 경과 감7화음, 세컨더리 도미넌트,
  add9 · maj9 · 6/9 · 7b9 · 13 · 7alt 텐션, 차용 화음(iv · bVI · bVII), 트라이톤 대리, 라인 클리셰를 담는다. 한 마디 안의 코드 변화는 이런 경과 · 해결 지점에만 쓴다.
- 고정 코드(ChordFamily)는 종류별 7음 모드 위에 3도를 쌓는다: major 는 Lydian(11도가 #11), minor 는 Dorian, dominant 는 Mixolydian, diminished, halfDiminished 는 Locrian ♮2.
  카탈로그 심볼로 고정한 코드(add9, 7sus4, 6/9, 7b9 …)는 복잡도 + 2 개 안에서 카탈로그에 있는 가장 긴 앞부분을 쓴다 (add9 는 3화음에서 maj, 7th 부터 add9).
  7alt 처럼 앞부분([0,4,6])이 카탈로그에 없는 심볼은 3도 · 7도로 패밀리를 추론해(도미넌트) 그 모드로 쌓는다. 덕분에 복잡도가 모든 진행에 같은 뜻으로 적용되고 progressionText 가 nil 이 되지 않는다.
- 조성을 고정한 진행을 곡 생성에 쓰면 brief 의 스케일도 그 조성(GenerateRequest.effectiveScale)을 따른다. 아니면 brief 는 C 단조, backbone 은 C 장조 코드를 말해 프롬프트가 자기모순이 된다.
  카탈로그에 min6 · 7sus4 · 9sus4 · m(add9) 를 더했고, min6/m6 별칭이 min 으로 뭉개지던 것을 고쳤다.
- 패턴 듣기는 위 성부를 Theory.voiceLead 로 잇는다. 후보는 각 전위를 옥타브 위아래로 옮긴 것 중 50...86 에 드는 것, 비용은 이전 보이싱과의 양방향 최근접 거리 합 + 가운데(66)로 당기는 항.
  근음 자리 보이싱을 그대로 늘어놓으면 코드마다 위 성부가 크게 뛰어 텐션이 거칠게 들린다. 베이스 채널이 근음(슬래시 코드는 지정 베이스)을 따로 치므로 위 성부는 어느 전위든 된다.
  코드 듣기(단일 코드)와 곡 전개(Arranger)에는 적용하지 않았다.
- Preview.progression 은 코드마다 자기 박 수만큼 코드 패턴과 베이스를 깐다. ChordPattern 의 grid/stepped 는 beats 가 4 미만이면 거기서 끊긴다.
- 곡 생성 프롬프트의 harmonic backbone 은 Theory.chords(of:) 로 풀고, 슬래시 베이스("/B")와 4박이 아닌 박 수("(2 beats)")를 붙인다.

### Groove: 진행 · 프레이즈에 묶인 드럼 (ListenOptions.groove, ⌥R)
- 진행과 프레이즈마다 어울리는 DrumPattern 을 데이터에 묶었다. Groove 를 켜면 패턴 듣기는 진행의 드럼(없으면 리듬 패턴 설정), 멜로디 듣기는 프레이즈의 드럼(없으면 없음)을 리듬 채널로 함께 보낸다.
  드럼은 기존처럼 GM 드럼 노트다. 템포는 묶지 않았다. 음색 시험은 사용자가 정한 BPM 으로 듣는 것이 맞다.
- 드럼 패턴을 7개에서 16개로 늘렸다. 기본(Swing 추가: 라이드 51 · 페달 하이햇 44), 모던 팝(Pop 16th · Half-time · Disco · Motown · Breakbeat), 어반(Boom Bap · Trap · Reggaeton · Afrobeats).
  모두 GM 드럼 노트 35...59 안(클랩 39, 탬버린 54)이라 기존 GM 검사가 그대로 맞는다. 오픈 하이햇 자리에는 클로즈 하이햇을 넣지 않는다 (GM 초크 그룹이라 같은 tick 이면 오픈이 바로 끊긴다). 트랩의 마디 끝 32분음표 롤 때문에 드럼 노트 길이를 구간 끝에서 자르게 했다 (MIDI 파일 끝 tick 이 어긋났다).
  곡 생성 단계 순서는 그루브가 성격을 정하는 패턴(Disco · Breakbeat · Boom Bap · Trap · Reggaeton · Afrobeats · Swing)은 리듬 먼저, Pop · Half-time · Motown 은 베이스 먼저다.
- UI 는 옵션 패널의 새 칸 대신 멜로디 줄과 패턴 줄에 같은 옵션을 가리키는 칩("Groove · Rock 8th")으로 두었다. 옵션 패널에 칸을 더하면 EXTEND/OCTAVE 라벨이 세로로 꺾였다.
  같은 이유로 복잡도 토글은 패턴 줄 오른쪽에서 자기 줄로 내렸다. DarkMenu 는 섹션(groups)을 지원하고 width 를 minWidth 로도 써서 좁은 줄에서 라벨이 사라지지 않게 했다.

## 채보 주의
프레이즈는 기억에 의존해 적었다. 음정은 확인했지만 리듬 세부(Take On Me 후반, Greensleeves 종지, Minuet 8마디)는 판본에 따라 다를 수 있다.
확신이 없는 곡(Yesterday, Final Countdown, Careless Whisper, Swan Lake)은 넣지 않았다. 고칠 때는 Phrase.swift 의 표기 문자열만 바꾸면 된다.
